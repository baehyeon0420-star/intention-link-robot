## 7. 보조 근거

- **9/21 로봇 실측 `run.log`**: 최대 수축 보정(rest 2,735, 최대 3,537). 쥐는 동안 정규화 0.16~0.44 를 오가며 GripClose 51회 vs Release 137회 (뒤집힘의 실물 기록). 9/21 커밋 8bdd7a3 본문: "기존엔 쥐기 판정이 최대 힘의 ~70% 이상에서야 나와서 꽉 쥐어야 했음. 녹화 재생 GripClose 57~74% → 93~99.8%".
- **최대 수축 반복 시 감소**: n1 이틀 연속 1회차 2,700~2,900 → 이후 1,000대(35%). **n5·n7 은 해당 없음**(n5 는 4회차 2,927 만 높고, n7 은 1·4·5회차가 높음 → 회차마다 떨어지는 패턴이 아니라 변동이 큰 것). 편한 쥐기는 n1 102%, n3 101%, n4 100%, n7 ±10% 유지. (n3, n6 는 최대 쥐기도 유지 → 사람마다 다름, n1 만 보조 근거로)
- **평균·표준편차 보정 붕괴**: 9/22 rest 표준편차 1,650(스파이크) → 임계 8,248(ADC 범위 초과). 9/22 오전 s5 6회 중 4회 접촉 실패(평균 147~449)가 평균으로는 약한 쥐기와 구분 불가 → 0·4095 제외 + 중앙값 도입 근거.
- **로봇 USB 연결 시 접지 간섭 (9/24 실측)**: rest 중앙값 138 → 2,748, 표준편차 93 → 294. 서보 별도 전원·노트북 배터리 구동에서도 동일. USB 데이터선 접지 공유가 원인 → USB 아이솔레이터(ADuM3160) 필요. 편한 쥐기 기준은 신호 여유가 작아 이 조건에서 최대 수축 기준보다 먼저 무너짐(9/24 캘리브레이션: rest 2,559 vs 편한 쥐기 2,867, 폭 308) → 전기적 분리가 전제 조건. 실물 로봇 로그는 논문에서 제외, 한계·향후 과제로.
